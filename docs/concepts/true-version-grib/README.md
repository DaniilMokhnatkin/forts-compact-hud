# ♂ True Grib Version ♂ artwork

The user approved the mushroom art direction and then asked for a solid whole
mushroom cursor and this exact display name. The concept sheet is a visual
proposal, not a screenshot or proof of in-game rendering. Its earlier outline
cursor study is superseded by the production solid mushroom sprite.

Production ImageGen originals and their exact prompts are in
`textures/grib/generated/`. `tools/build_grib_hud.py` crops the documented atlas
cells, removes faint halo alpha, fits sprites to the original game texture
bounds and creates DDS files and functional button glyphs.

The seven alert icons preserve their meaning: extinguisher, construction,
upgrade, repair, reload, banked ammunition and demolition. The separate solid
cursor is also used as the mushroom emblem on the commander controls.
